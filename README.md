# Task Completion Token (TCT)

This project demonstrates the creation and deployment of a custom ERC20 token called **Task Completion Token (TCT)** using Solidity, Remix IDE, MetaMask, and SecureChain Mainnet.

The smart contract was successfully deployed on blockchain and the token was imported into MetaMask wallet.

---

# Technologies Used

- Solidity
- Remix IDE
- MetaMask
- SecureChain Mainnet
- GitHub

---

# Token Details

| Property | Value |
|----------|-------|
| Token Name | Task Completion Token |
| Token Symbol | TCT |
| Total Supply | 1000 Tokens |

---

# Project Steps

1. Installed MetaMask wallet
2. Added SecureChain Mainnet
3. Collected faucet SCAI tokens
4. Opened Remix IDE
5. Created Solidity smart contract
6. Compiled the smart contract
7. Connected MetaMask with Remix
8. Deployed the smart contract
9. Imported TCT token into MetaMask
